# Price Monitor Bot

Telegram-бот для мониторинга цен. Пользователь присылает ссылку на товар и желаемую цену, бот периодически проверяет страницу и присылает уведомление, когда цена опускается до порога или ниже.

## Возможности

- Добавление товара одним сообщением: `https://shop.ru/product/123 1500`
- Если прислать только ссылку — бот покажет текущую цену и спросит порог
- Список отслеживаемых товаров с кнопками удаления (`/list`)
- Проверка цен по запросу (`/check`) и автоматически раз в N минут
- Повторное уведомление, если цена упала ещё ниже; после подъёма выше порога следующее падение снова придёт уведомлением
- Предупреждение, если цену товара не удаётся получить несколько раз подряд
- Хранение данных в SQLite, лимит товаров на пользователя

## Как бот находит цену

1. Разметка schema.org `Product` в JSON-LD — её используют большинство интернет-магазинов
2. Мета-теги `product:price:amount` / `og:price:amount`
3. Микроразметка `itemprop="price"`
4. Эвристика: элементы с `price` в классе/id и символом валюты (зачёркнутые и «старые» цены пропускаются)
5. Для Wildberries — публичный API карточек товара

**Ограничения.** Сайты с сильной антибот-защитой или полностью клиентским рендерингом (Ozon, Lamoda, Ситилинк, М.Видео и т.п.) могут не отдавать цену простому HTTP-запросу — в этом случае бот сообщит, что цену определить не удалось. API Wildberries закрыт для части IP-адресов (в том числе зарубежных), поэтому для WB боту лучше работать с российского сервера.

## Команды

| Команда | Описание |
|---|---|
| `/start`, `/help` | Справка |
| `/list` | Мои товары |
| `/check` | Проверить цены сейчас |
| `/threshold <номер> <цена>` | Изменить порог |
| `/remove <номер>` | Перестать следить |

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости (Python 3.10+):

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
4. Запустите:

   ```bash
   python -m bot
   ```

### Docker

```bash
docker build -t price-monitor-bot .
docker run -d --name price-bot --env-file .env -v price-bot-data:/app/data price-monitor-bot
```

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен Telegram-бота (обязательно) |
| `CHECK_INTERVAL_MINUTES` | `30` | Период проверки цен |
| `DB_PATH` | `data/bot.db` | Файл базы SQLite |
| `MAX_ITEMS_PER_USER` | `20` | Лимит товаров на пользователя |

## Структура

```
bot/
  __main__.py   запуск бота и фонового мониторинга
  config.py     настройки из .env
  db.py         хранилище SQLite
  handlers.py   команды и диалог в Telegram
  monitor.py    периодическая проверка цен и уведомления
  parsers.py    извлечение цены со страницы товара
tests/          тесты парсера и логики уведомлений
```
